cv-job-match control panel

Tweak filters → refresh this week's jobs → score → select → build packages.

1 · Filters

Edits config/search-profile.yaml directly; saving re-syncs the n8n weekly scrape.

2 · CV

Replace context/cv-master.md / cv-master-fr.md from a PDF. Nothing is written until you approve the diff.

3 · This week's jobs

Scrape files from the Drive JobApplications folder, filtered through the pipeline.

4 · Build packages

Generates a tailored CV excerpt + cover letter + LinkedIn message per selected job (saved to applications/… and mirrored to Drive). Builds only — this tool never applies or sends anything for you.
