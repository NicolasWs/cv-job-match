## Project Storytelling (STAR) — 3 stories picked for this posting

### 1. Broker-Voting App (AI-native, consumer-facing shipping)
- **S:** French asset manager needed analysts to vote on data-provider
  performance, no existing tool.
- **T:** Design and ship a usable web app fast, without a large team.
- **A:** Ran the entire build on an AI-assisted SDLC (Angular, .NET, SQL
  Server), owning scope, UI decisions, and delivery pipeline personally.
- **R:** Live in production on the client's own Azure Cloud in under two
  months from kickoff (May–Jun 2025).
- **Learning:** Tight scope + AI-assisted tooling can compress a
  traditional multi-quarter build into weeks without sacrificing quality.

### 2. Opensee Ingestion Pipeline (specs → acceptance criteria → launch)
- **S:** Opensee's early SaaS ingestion pipeline lacked formal
  reconciliation and pre-ingestion data controls.
- **T:** Define and ship the pipeline's requirements from scratch.
- **A:** Wrote user stories, prototyped flows in OpenMetadata, then handed
  off for industrialization in Apache NiFi; ran the data-quality reporting
  and anomaly-tracking process alongside launch.
- **R:** Delivered 99% uptime against a 95% contractual target across the
  first six months of production; weekly CTO reporting throughout.
- **Learning:** Prototype-first specs reduce rework once engineering
  industrializes the flow.

### 3. Woon/TradeValue AI POC (customer feedback → iteration → metric)
- **S:** TradeValue partners struggled with slow, manual candidate/mission
  matching.
- **T:** Build an AI-assisted matching POC and validate it with real
  recruiter feedback.
- **A:** Designed early automation of the matching logic, ran feedback
  loops with recruiters to refine it.
- **R:** 40% reduction in sourcing time, improved placement quality.
- **Learning:** Feedback loops with the people doing the work daily catch
  the assumptions a model alone would miss.
